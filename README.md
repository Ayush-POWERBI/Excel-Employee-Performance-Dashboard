# 📊 Employee Performance Analysis & Excel Dashboard

## 📌 Project Overview

This project is an Excel-based Employee Performance Analysis and Interactive Dashboard.

The project analyzes employee working hours, break patterns, work efficiency, call performance, and active time with customers.

Raw data from multiple datasets was analyzed and transformed into meaningful insights using Excel formulas, PivotTables, PivotCharts, and VBA automation.

---

## 🎯 Project Objectives

- Analyze employee working hours
- Analyze break patterns
- Measure employee work efficiency
- Analyze call performance
- Analyze active time with customers
- Create a consolidated employee performance summary
- Build an interactive Excel dashboard
- Use VBA for dashboard automation

A consolidated employee performance summary was created using Excel formulas and lookup functions.

### Formulas Used

- MID
- FIND
